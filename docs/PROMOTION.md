# Promotion Notes

Use this when introducing the project in GitHub topic pages, awesome lists, forums, or short launch posts.

## One-Line Pitch

`speech-to-text-zh` is a local Windows GUI and CLI for Chinese Whisper transcription that outputs Word, TXT, SRT, JSON, and separates low-confidence segments for review.

## Best Audience

- Chinese users transcribing meetings, classes, interviews, or voice notes
- Windows users who do not want to manage Whisper commands manually
- People who prefer local transcription over uploading audio to a web service

## Launch Post Template

I built `speech-to-text-zh`, a small local Windows tool for Chinese speech-to-text.

It wraps Whisper with a GUI and CLI, then outputs Word, TXT, SRT, JSON, and a quality report. The useful bit is that uncertain segments are separated instead of being silently mixed into the final transcript.

Repo: https://github.com/yystudio-cyber/speech-to-text-zh

Feedback I want most: packaging problems, Chinese transcription edge cases, and whether the output files match real meeting/class workflows.
